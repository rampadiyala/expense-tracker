# Expense Tracker

A browser app to record and total expenses.

## Features

- Add, edit and delete expenses
- Automatic total
- Data saved with localStorage

## Tech stack

HTML, CSS, JavaScript

## How to run

`npm start` (needs Python 3), then open http://localhost:8000. You can also open `index.html` directly. No packages to install.

## Project files

- `index.html` - page and styles
- `app.js` - app logic

## Notes

Data stays in one browser and is not synced.
